| DEC-004 | 2026-08-11 | Set the default seeded store coordinates (`StoreSettingsSeeder.java`) to match the store's Google Maps place link pin (`.../maps/place/Home+Cafe+by+Bami/...!3d14.8690823!4d121.0430113...`) — coordinates unchanged (already correct), `storeAddress` kept as the full postal address `"048 Kay Piskal Rd, Tigbe, Norzagaray, 3013 Bulacan, Philippines"` | Accepted (amended) | Resolves Open Issue 1 (degraded address precision) at the seed level. **Amendment:** an initial version of this change set `storeAddress` to the bare place name `"Home Cafe by Bami"`, which a code-review pass caught as a regression — that field is shown verbatim to customers (footer, location banner, order-status page) and sent to Lalamove as the rider pickup-address text, so a bare business name loses street-level detail those consumers need, and it conflicted with the hardcoded address on the contact page.
